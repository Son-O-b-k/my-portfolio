About

A problem solver who likes the layer underneath the product.

Platform Engineer and Full Stack Developer with extensive experience architecting cloud infrastructure, developer platforms and large-scale hosting solutions.

I design containerized systems, automate infrastructure, and build scalable backend services in Golang and Node.js — alongside modern frontends in React, Next.js, Vue and TypeScript. Day to day that means Linux administration, Docker, Nginx, CI/CD pipelines and cloud server management across AWS and DigitalOcean.

Most of my work has been end-to-end platform building: container orchestration, reverse-proxy systems, shared hosting infrastructure, VPS management, DNS automation, email hosting, developer tooling and secure multi-tenant cloud environments. I care about solving complex infrastructure problems through automation, scalable architecture and clean software design.
